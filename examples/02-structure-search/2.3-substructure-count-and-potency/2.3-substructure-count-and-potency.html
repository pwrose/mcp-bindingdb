The list is dominated by 4-anilinoquinazoline EGFR inhibitors (gefitinib, erlotinib, lapatinib, afatinib, dacomitinib, canertinib), the best-known use of this ring. The same ring also appears in drugs for quite different targets: an alpha-blocker (prazosin), an antifolate (trimetrexate) and a DPP-4 inhibitor for diabetes (linagliptin).

Lesson: a substructure match is not a scaffold match. A substructure search finds every compound that contains the query anywhere. In linagliptin, the quinazoline is a side-chain substituent, not the core of the drug, and it still matches. Two more points:

  • Count first. With count_only you learn the size of the result (38,906 here) before you fetch rows. A plain listing is capped by limit and favours compounds with the most measurements, so it is not a random sample.
  • Aromaticity and tautomers. The query was written as aromatic SMILES. Vandetanib matched even though BindingDB stores it as a quinazolin-imine tautomer, because RDKit still treats that ring as aromatic. CHEMBL3359091 matched through a quinazolinone ring. If you need exactly one tautomer or ring form, write a SMARTS query (Example 2.4).

Best values are single measurements. For several of these drugs the typical (median) value is weaker. See Example 1.1 for how to check.

How this was answered

  1. substructure_search with quinazoline c1ccc2ncncc2c1 and count_only=true: 38,906 matching compounds across the whole database.
  2. substructure_search with the same query and max_value_nm=0.1, limit=15: matching compounds that have a measurement of 0.1 nM or better, each with its most potent such value, most potent first. With an affinity filter, the search runs only over compounds that have a qualifying measurement.
