👤 User

Find compounds with a 4-chloroaniline group. What changes if I require a free NH2 (primary amine)?

🧠 Assistant

Whether you require a free NH2 makes a 75-fold difference:

Query Written as What it means Matching compounds
Nc1ccc(Cl)cc1 SMILES a nitrogen on a ring carbon para to a chlorine, with any substitution on the N 21,350
[NX3;H2]c1ccc(Cl)cc1 SMARTS the same, but the N must carry exactly two hydrogens (a free -NH2) 283

So about 99% of the 4-chloroaniline hits have the nitrogen built into something larger: an amide, a urea, a ring or a secondary amine.

These are smaller and much less studied. The best-studied has only 19 measurements, compared with 1,731 for sorafenib. A free aromatic NH2 is uncommon in optimized drugs.

Lesson: SMILES describes a molecule, SMARTS describes a pattern. When you search with a SMILES string, the server matches it as a pattern made of the heavy atoms and bonds you wrote. Hydrogen counts are ignored, so N (or even [NH2]) matches a nitrogen with any number of substituents. To make a property part of the query, write SMARTS, which lets you state it per atom:

  • [NX3;H2]: a three-connected nitrogen with exactly two H (a primary amine).
  • [NX3;H1]: exactly one H (a secondary amine or amide NH).
  • [n] vs [N]: aromatic vs non-aromatic nitrogen.
  • [#7]: any nitrogen, whatever its form.

With query_type="auto" the server falls back to SMARTS when a query is not valid SMILES. If you need H counts enforced, set query_type="smarts" yourself.

How this was answered

  1. substructure_search with Nc1ccc(Cl)cc1 (SMILES) and count_only=true: 21,350 compounds.
  2. substructure_search with [NX3;H2]c1ccc(Cl)cc1, query_type="smarts" and count_only=true: 283 compounds.
  3. The same two searches with limit=8: example compounds, ranked by number of measurements. A listing is capped by limit (and scans the 100,000 best-measured compounds), so it shows the best-studied matches, not a random sample.
