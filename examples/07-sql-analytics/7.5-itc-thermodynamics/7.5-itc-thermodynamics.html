Show isothermal titration calorimetry (ITC) results for carbonic anhydrase II ligands: ΔG, ΔH and −TΔS.

🧠 Assistant

BindingDB has no ITC data for carbonic anhydrase II. All six CA II records (human, bovine, rat, M. tuberculosis and two human mutants) have zero ITC results. The ITC table is small, with 1,822 results in total, so most targets have none. I picked the target with the most complete ITC profiles that also passes a consistency check: human CDK2, with 20 results that have ΔG, ΔH and ΔS. (Purine nucleoside phosphorylase has more ITC rows, 40, but most of them lack ΔH and ΔS.)

The "Entry" column names the deposition. The CSAR benchmark sets measured CDK2 alone (entry 7953) and CDK2/cyclin A (entry 7952). K03861 comes from a separate paper on type II CDK2 inhibitors (entry 6856).

What the profiles show: ligands with similar affinity can bind in very different ways. CS261 and K03861 have almost the same ΔG (about −40 kJ/mol), but CS261's binding is mostly entropy-driven (−TΔS = −22.35), while K03861 is strongly enthalpy-driven (ΔH = −61.9) and pays an entropy penalty (+21.9). CS246 even changes profile between CDK2 alone and CDK2/cyclin A.

A lesson about raw tables: no units, no validation. The ITC table has no unit column, and units differ between depositions:

  • ΔG values of −27 to −40 only make physical sense in kJ/mol. −40 kJ/mol corresponds to a Kd of about 100 nM. In kcal/mol the same numbers would imply impossibly tight binding.
  • Other entries use kcal/mol. The table's sample rows include ΔG = −10.4, a typical kcal/mol value.

So check every row against ΔG = ΔH − TΔS. The check_residual column does this and is about zero for well-formed rows. Three rows fail it: CS3 (−TΔS = +1683.7, probably ΔS entered in J instead of kJ), CS1 (residual 46.39) and CS4 (residual 7.08). Exclude them or look up the original paper before you use them. The same check over all targets flags others too. For example, yeast cytochrome c peroxidase has a median mismatch of 6.3.

How this was answered

  1. run_sql ranks targets by number of ITC results. The protein can sit in the calorimeter cell or the syringe, so the query checks coalesce(cell_polymerid, syr_polymerid).
  2. run_sql confirms that CA II has no ITC results.
  3. run_sql finds the targets with complete ΔG/ΔH/ΔS profiles and measures how far each is from ΔG = ΔH − TΔS.
  4. run_sql lists the CDK2 results with the consistency check, sorted so the problem rows come first.
  5. run_sql looks up the entry table to see what distinguishes the two CSAR depositions.
