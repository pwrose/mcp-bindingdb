Seven of the ten are kinases, which reflects how much of drug discovery has gone into kinase inhibitors. hERG is the odd one out. It is not a therapeutic target: compounds are tested against it routinely because blocking it can cause dangerous heart-rhythm problems. It ranks third only because so many unrelated compounds are screened against it as a safety check.

A lesson about counting "targets". BindingDB stores every mutant and construct as a separate target record. EGFR has 49 of them, for example "Epidermal growth factor receptor [S768I]". If you GROUP BY polymerid or by target_name, EGFR splits into 49 rows and drops down the ranking. Grouping by uniprot pools them, and count(DISTINCT polymerid) shows how many records were merged. A first version of this query used any_value(target_name) and got construct names like "JAK2 [536-812,W659A,...]" as labels. The final version takes the shortest name, which is usually the wild-type record.

Two more choices worth noticing:

  • count(DISTINCT monomerid) counts compounds, while count(*) counts measurements. EGFR has more measurements than JAK2 (30,293 vs 25,187) but fewer distinct compounds.
  • uniprot IS NOT NULL keeps single proteins and leaves out multi-subunit complexes, which have no single UniProt accession.

How this was answered

  1. One run_sql query on the activity table: filter to human, group by UniProt accession, count distinct compounds, sort and keep the top 10.
