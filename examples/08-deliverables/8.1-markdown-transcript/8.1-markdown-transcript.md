**What is in a Markdown transcript.** It has a header (date, model, BindingDB release, server version), then each of your prompts with my answer, verbatim and in order. If a turn produced figures (structure grids, plots), they are linked from a `figures/` subfolder next to the .md file. There were none in this conversation. Tool calls are *not* included unless you ask for them (see Example 8.2).

**Why Markdown?** It is plain text, so you can read it in any editor, diff two versions in git, paste it into a notebook or wiki, or edit it before sharing. If you edit it, you can still turn it into a web page later with `transcript_to_html`.

**The lesson: the server writes the files, not the assistant.** The assistant cannot see its own earlier answers as files, so it passes each prompt and its full answer to `create_transcript`, and the server writes the document. Name the folder you want, as in this prompt. Otherwise the file goes to the server's default transcripts folder.
