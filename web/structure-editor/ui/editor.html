STRUCTURE STUDIO

From a sketch to a reviewed query.

  1. Choose an input. SMILES describes a molecule; SMARTS describes a query. For names, review the source and select a candidate.
  2. Draw or edit. Use JSME’s bond, ring, element, and stereo tools. Generated SMILES updates as you draw. Use its undo arrow to reverse an edit.
  3. Inspect. Review stereo, charge, salts, and the rendered structure. A parsed name is a candidate identity, not a guarantee.
  4. Prepare. Exact matches use full canonical isomeric SMILES. Substructure supports explicit SMARTS. Similarity follows the repository’s Morgan radius 2, 2,048-bit Tanimoto on the largest fragment.

SMARTS cannot generally be converted to a unique molecule or SMILES. Its original query is kept intact. The drawing preview may simplify labels; the query text is authoritative.

Affinity defaults to 0–1000 nM, inclusive. Any accepts a compound with at least one qualifying Ki, Kd, IC50, or EC50 measurement; these types are kept distinct in results. Turn off Affinity to search without this filter. Values reported as > are excluded. Values reported as < are accepted only when the minimum is zero and the reported upper bound is within the range.

In chat, Run query submits the reviewed search to your assistant. A connected BindingDB search service is required for results. The standalone workspace prepares structures without running searches.

Automatic name resolution tries BindingDB, PubChem, then OPSIN. Select the intended candidate before running a search. The server’s network settings apply.
